# Les maths de Papounet

Une curiosité mathématique par jour : un problème, un paradoxe, un fait peu connu ou une belle démonstration, avec des schémas et une solution expliquée pas à pas.

- Une nouvelle fiche apparaît chaque jour à minuit. Les fiches suivantes restent cachées.
- Toutes les fiches déjà parues sont dans la liste en bas de la page.
- Les boutons **A−** et **A+** changent la taille du texte.
- Pour voir toutes les fiches d'un coup (aperçu), ajouter `#apercu` à la fin de l'adresse.

Le site est un seul fichier, `index.html`, publié avec GitHub Pages.
